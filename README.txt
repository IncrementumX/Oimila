Dinner invite mini form (editorial multi-step flow). Open index.html in a browser or host the folder as a static site. Responses are stored in Supabase table public.personal_dinner_invite_responses (response values: oi, nada_a_ver, sim_jantar, recusou_jantar). Public visitors can INSERT, and can SELECT rows scoped to this invite so the discreet in-page viewer (tap the small dot bottom-right 5 times fast) can list answers. To keep responses private, drop the SELECT policy in schema.sql and read them from the Supabase dashboard instead.
